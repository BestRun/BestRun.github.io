吸引

健身时闲来无事，反思一下自己到底会被什么样的人吸引（无论性别）。 因为我朋友跟我说，你反省一下自己，为什么总是吸引不到正确的人。 所以分两方面吧：我容易被什么样的人吸引，以及我有概率吸引到什么样的人。 我觉得吸引也分两部分：一种是欣赏角度的吸引，一种是生活陪伴意义上的吸引。 从欣赏的角度来说，我很容易欣赏这样一种人：强者，有明确的目标、独立的想法，并愿意为之放弃很多，resilient、独立。 为什么？因为我觉得这是我欣赏的态度，也是我一直践行的态度。 比如刚到丹麦的时候，我遇到了 Black 同学。我只跟他聊了几次，就觉得我们本质上是十分相似的人。他是那种在混乱的世界中，依然愿意坚守自己理想的人。简单点说，就是有自己的想法，并且愿意为之付出努力。 他跟我说过一句让我印象很深的话：“如果读博期间有一天，我发现我认为自己的研究方向已经被解决了，我可能就会放弃读博，去做个 bartender。” 果然，在一年内，他在 HCI 方向连发了几篇顶会，也拿到了几个非常好的博士 offer。 我的老友 Oswin，是我的高中校友，现在在 Oxford 读 Physics 的 PhD。他和我一起度过了高中的竞赛时光，本科期间我们也一直互相努力。最后，他先我一步去了 Oxford 读博士，而我也还在申请中。我们都选择了学术这条道路。 我们有相似的理想：希望在自己的领域内做出一些改变；我们也都憧憬未来，并相信只有自己才能拯救自己。 我觉得我们对于彼此来说，都是为数不多能够真正相互理解的人。当然，我觉得这种理解建立在相似的经历之上，需要十年的筛选，甚至还需要一点聪明，才能够真正理解对方。 从生活陪伴上来说，如果我们处得来，大多是因为我们有还算 match 的背景，有相同的爱好，比如健身、喝酒，或者对方能给我一些我觉得有用的建议，比如情感上的建议。 在丹麦遇到的 Wen 陪我度过了在丹麦最抑郁的几个月。我们每天健身、坐图书馆。我觉得这种算是陪伴意义上的吸引。 但欣赏和喜欢是两回事。 Oswin 跟我说，他现在找另一半的标准，就是对未来的规划一致，并且能够理解他在做什么。 我说，那要求有些太具体了吧？难道还必须是学物理的？学化学的博士就不行？ 他笑了笑说，学化学的也不是完全不能理解我在做什么。 他说，他绝对不会找年龄小一些或者不成熟的人。他还笑着跟我说：“你经历了就知道自己希望的另一半是什么样的了，只不过对你来说，心动来得有些太晚了。（老了老了）” 你问我怎么看。 我觉得我可能还是有些理想主义吧，希望能从对方身上找到我缺失的那一部分。但事实证明，这似乎确实不是一个很好的选择。 可我又不喜欢那种只被我好的一面吸引的人。我会觉得，对方并不理解我的脆弱，也不理解我隐藏起来的另一面。 所以就很矛盾。 我是不是太作了，要求太多了。 就讲这么多吧。 只是缘分未到。

对AI安全的一些思考

好久没冒泡了，简单解释一下我现在的状态。 在TUM交换快乐玩耍，下学期要去 CISPA 做毕设。 但是最近 CISPA 出了点状况（危），导致我不得不考虑重新审视一下未来。 与其说是对AI和安全的一些思考，不如说是对自己的一个深度探索。 最近在cispa做了一项 benchmark 的工作，（本来说是为博士的研究提前做数据集，现在看来也可能就只是一篇benchmark文章了）。 AI安全，最近非常热门的一个方向。无论是学术界还是工业届都有越来越多的人涌入。可能最近经常有各种新闻，claude的xxx模型，挖出了xxx个firefox漏洞，等等等等。所以，AI在安全上的能力到底发展成什么样子呢？我觉得我还是有资格可以讲一讲的。 但细分的话AI安全，可以分为两个方面: AI for security 和 AI security. AI security 本质上就是 AI 自己的安全，在学术界，早期就是各种测 prompt injection（早就被玩烂了），现在可能焦距到 agent 的 security 和如何做防护上。在工业界，大家关注的更多还是业务中 AI 服务的安全性（这里我没有太多发言权）。 更想说一说的是 AI for security, 我们从 AI 能够解一些数学题，在各种 reasoning benchmark 上得分越来越高，可以看出 AI 在 security 领域有着巨大的潜力。于是相应的安全方面的 benchmark 诞生了，UCB团队做了 cybergym, exploitgym 用于测试 agent 在安全领域的能力。但是模型和agent的能力越来越模糊，（跑偏了，不是来讲现有研究的limitation的）。 至少我觉得 AI for security 是有无限可能的，虽然有些朋友并不看好这块。那么在学术界还是工业界做成了我最近一直在思考的问题。学术界，计算资源会紧缺一些，但是胜在自由度高，你想研究的课题比较自由。工业界胜在资源丰富，但缺点是总要为业务服务，很难去做自己想做的的研究。 我觉得去工业界需要考虑以下几个维度： 入场时机 x 发展前景 x 自身 总入场时机的角度：现在无疑是最好的入场时机，LLM 的 reasoning 能力飞速提升（这学期选了一个reasoning相关的seminar，读了很多相关领域的论文，其实这块还有很大的提升空间），缺的是数据和垂直的训练方法。如果现在入场，无疑是很好的的一个时机，能在该领域积累经验。 发展前景：首先，“钱”景肯定是不错的，但是会不会有天花板的存在，这个还不好说。因为没有接受博士的训练，可能工程能力和科研能力无法balance。 自身的角度：这个我觉得是最重要的，那就是我究竟适合哪条道路。其实相比于长期无正反馈，我喜欢那种短期的刺激感。可能是因为，我是安全竞赛的走出来的半学院派，而非传统的科研人。所以我迟疑了，博士能带给我的，真的值得吗，如果这三年我花在业界，也许已经可以攒一部分名气。
